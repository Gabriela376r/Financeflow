# Financeflow
Sistema web de controle financeiro pessoal.
o FinanceFlow é uma aplicação desenvolvida para facilitar a organização financeira, permitindo acompanhar receitas, despesas e saldo disponivel por meio de um dashboard intuitivo.

Funcionalidades
. Cadastro de receitas
. Cadastro de despesas.
. Cálculo automático do saldo disponivel.
. Histórico de movimentações financeiras.
. Filtro de movimentações por categoria.
. Dashboard com resumo financeiro.

TECNOLOGIAS UTILIZADAS
. HTML5
. CSS3
. JavaScript

Demonstração
o projeto possui uma interface com dashboard financeiro, formulário de Lançamentos e relatórios de movimentações.

Como executar 
1. clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo index.html Utilizandoa extensão live server
